Политика конфиденциальности приложения «Вовремя»

Действует с версии 1.1.0. Дата последнего изменения: 30 августа 2026 года.

Приложение «Вовремя» (ru.vinteno.vovremya, далее — приложение) помогает

планировать режим сна: задаёт окно отхода ко сну, напоминает о нём вечером и

будит утром.

Этот документ написан коротко и по-человечески. Если после него остались

вопросы — значит, документ плохой, и его надо переписать.

Коротко

Данные о вашем сне остаются на телефоне. Время отхода ко сну, время

подъёма, самочувствие, история ночей, настройки режима — всё это хранится в

локальной базе на устройстве и никуда не передаётся.

**Обезличенная статистика использования отправляется только с вашего

согласия.** По умолчанию сбор выключен, и до вашего ответа приложение не

отправляет наружу ничего — сервис статистики даже не запускается. Согласие

можно отозвать в настройках в одно нажатие.

Аккаунта нет. Приложение не спрашивает имя, почту и телефон, не требует

регистрации и не может связать данные с вашей личностью.

1. Какие данные остаются только на устройстве

Никогда не покидают телефон:

  • время подъёма, целевая длительность сна, время на засыпание, ширина окна;
  • фактическое время отхода ко сну и подъёма по каждой ночи;
  • отметка самочувствия;
  • история ночей и статистика режима;
  • настройки будильника и напоминания.

Эти данные хранятся в базе внутри приложения. Их можно выгрузить в файл

самостоятельно («Настройки → Сохранить в файл») и удалить целиком («Настройки →

Удалить все данные»). При удалении приложения они удаляются вместе с ним.

2. Какие данные передаются

Только после вашего согласия приложение использует Яндекс AppMetrica

для статистики использования и сбора отчётов о сбоях. До согласия сервис не

инициализируется, то есть ни один из перечисленных ниже пунктов не передаётся.

Приложение не собирает геолокацию, контакты, содержимое файлов, рекламный

идентификатор. Соответствующие разрешения из приложения удалены явно.

3. Как отказаться

Согласие спрашивается один раз: у новых пользователей — в конце первоначальной

настройки, после проверки будильника; у тех, кто обновился с версии 1.0.0, — при

первом запуске новой версии. Обе кнопки на экране равнозначны, отказ не требует

дополнительных действий.

Отозвать согласие: «Настройки → Отправка статистики». Переключатель

останавливает передачу данных.

4. Кому передаются данные

Обработчик статистики — ООО «Яндекс» (сервис AppMetrica). Условия

обработки — на стороне сервиса: https://yandex.ru/legal/confidential/.

Другим третьим лицам данные не передаются. Данные не продаются и не

используются для рекламы.

5. Дети

Приложение не предназначено специально для детей и не собирает данные,

позволяющие определить возраст. Возрастная категория — 0+.

6. Изменения политики

Существенные изменения отражаются в этом документе и в описании приложения в

магазине. Если изменится состав передаваемых данных, приложение сообщит об этом

внутри интерфейса, как это было сделано при переходе с версии 1.0.0.

7. Обратная связь

Вопросы по обработке данных — через страницу приложения в RuStore.

Оговорка, не относящаяся к данным

Приложение помогает планировать режим сна. Оно не является медицинским

изделием, не диагностирует и не лечит нарушения сна. При постоянных проблемах

со сном следует обратиться к врачу.
